# 📅 Event Manager — Система управления мероприятиями

Веб-приложение для создания, просмотра, редактирования и удаления мероприятий.  
Разработано в рамках учебной практики (ПМ.02).

## 🚀 Функциональность

- ➕ Добавление мероприятий (название, описание, дата, место, категория)
- 📋 Просмотр списка всех мероприятий в таблице
- ✏️ Редактирование любого мероприятия
- 🗑️ Удаление с подтверждением (через POST-запрос)
- 📅 Хранение даты в типе `Date` (корректная сортировка)
- 🎨 Адаптивный интерфейс на Bootstrap 5

## 🛠️ Технологии

| Компонент | Технология |
|-----------|------------|
| Backend | Flask |
| ORM | SQLAlchemy |
| База данных | SQLite |
| Frontend | HTML, Bootstrap 5 |
| Язык | Python 3.9+ |

📝 Как пользоваться
На главной странице нажмите «Перейти к мероприятиям»

Для добавления — кнопка «Добавить мероприятие»

Для редактирования — кнопка «✏️ Ред.» у нужной строки

Для удаления — кнопка «🗑️ Удалить» (с подтверждением)

🗄️ База данных
Файл events.db создаётся автоматически при первом запуске
Поле date хранится в типе Date, а не строке
